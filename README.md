# 🐾 PawCare Clinic Management System

A full-stack web application designed to streamline pet registration, owner record management, and clinic tracking. Built as a portfolio project to demonstrate practical full-stack development skills using Java and modern web technologies.

## 🛠️ Tech Stack
* **Backend:** Java, Spring Boot, Spring Data JPA, H2 In-Memory Database, Maven
* **Frontend:** HTML5, CSS3, JavaScript (ES6+), Bootstrap 5
* **Architecture:** RESTful API

## ✨ Key Features
* **Pet & Owner Registry:** Register new pets linked with owner contact details.
* **Dynamic Dashboard:** View all registered pets in a clean, responsive data table.
* **Real-Time Search:** Instant filtering of records by pet name or species.
* **Record Management:** Add, view, and delete clinic records seamlessly through backend integration.

## 🚀 How to Run Locally

### Prerequisites
* Java Development Kit (JDK 17 or higher)
* Eclipse IDE or any Java-supported IDE
* Any modern web browser

### Running the App
1. Clone and run the Spring Boot backend in Eclipse (`http://localhost:8080`).
2. Open `index.html` from this frontend repository in any modern web browser.
